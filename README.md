# ✨ ZenTask (젠태스크) - 프리미엄 스마트 To-Do List & 업무 관리

현대적인 글래스모피즘(Glassmorphism) 디자인과 다채로운 인터랙션, 칸반 보드 및 생산성 통계를 제공하는 올인원 웹 애플리케이션입니다.

---

## 🌟 주요 기능 및 특징

1. **🎨 최신 모던 UI & 듀얼 테마**
   - OLED 딥 다크 모드 & 클린 라이트 모드 (실시간 전환 및 로컬 저장)
   - 은은한 블러 배경(Frosted Glass), 네온 액센트, 부드러운 스프링 모션
   - 완벽한 반응형 레이아웃 (모바일, 태블릿, 데스크톱)

2. **📋 다중 뷰 (리스트 & 칸반 보드)**
   - **리스트 뷰**: 오늘 할 일, 다가오는 일정, 기한 지연 작업, 중요 작업 필터링
   - **칸반 보드 뷰**: '할 일(To Do)', '진행 중(In Progress)', '완료(Done)' 컬럼 간 **드래그 앤 드롭** 이동 지원

3. **⚡ 고속 할 일 등록 & 스마트 체크리스트**
   - 상단 빠른 등록 바(Quick Add)를 통한 즉시 생성
   - 상세 모달: 제목, 메모, 우선순위(긴급/높음/중간/낮음), 카테고리 태그, 마감일시, 상단 고정(Pin)
   - 동적 하위 서브태스크(Checklist) 및 실시간 미니 프로그레스 바

4. **📊 생산성 분석 & 스트릭(Streak)**
   - SVG 원형 달성률 프로그레스 링 (실시간 % 반영)
   - 일일 연속 달성 스트릭(Streak Counter)
   - 카테고리별/상태별 카운트 뱃지

5. **🎉 축하 파티클 & 사운드 엔진 (Zero Dependency)**
   - 완료 시 Canvas 물리 시뮬레이션 기반 **폭죽 파티클(Confetti)** 효과
   - 100% 달성 시 축하 멜로디 및 축포 효과
   - Web Audio API 기반 무의존성 사운드 (추가음, 완료음, 삭제음, 음소거 토글)

6. **💾 데이터 영속성 & 백업/복원**
   - `localStorage` 자동 동기화
   - JSON 파일 데이터 다운로드(Export) 및 복원(Import) 기능
   - 데모 샘플 데이터 초기화 기능

7. **⌨️ 생산성 단축키 시스템**
   - `N` : 새로운 할 일 등록 모달 열기
   - `/` : 실시간 검색창 포커스
   - `T` : 다크 / 라이트 테마 전환
   - `1` : 리스트 뷰 전환
   - `2` : 칸반 보드 뷰 전환
   - `Esc` : 모달 닫기
   - `?` : 단축키 가이드 보기

---

## 🚀 실행 방법

별도의 서버 설치나 빌드 과정 없이 `index.html` 파일을 웹 브라우저(Chrome, Edge, Safari 등)에서 더블 클릭하거나 열면 즉시 실행됩니다.

```bash
# 기본 브라우저로 바로 열기 (Windows)
start index.html
```

## 📁 프로젝트 파일 구조

```
ToDoList/
├── index.html        # 메인 웹 페이지 마크업 (시맨틱 구조, 모달, 네비게이션)
├── css/
│   ├── style.css     # 코어 디자인 시스템, 테마 변수, 레이아웃, 컴포넌트
│   └── animations.css# 마이크로 애니메이션, 트랜지션, 펄스, 글래스모피즘
├── js/
│   ├── app.js        # 메인 진입점, 이벤트 리스너, 단축키, 드래그앤드롭
│   ├── store.js      # 상태 관리(Store), CRUD, 로컬스토리지, 통계
│   ├── ui.js         # UI 렌더링 엔진 (리스트, 칸반, 통계 링, 모달, 토스트)
│   ├── confetti.js   # Canvas 파티클 축하 폭죽 효과 엔진
│   └── sound.js      # Web Audio API 사운드 합성 엔진
└── README.md         # 프로젝트 문서
```
